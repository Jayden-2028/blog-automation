# 쌍둥이 아빠 육아 블로그 원고 작성

> ⚠️ 이 스킬을 수정하면 `blog-automation` 저장소의 `prompts/writing/style/parenting.md`도 함께
> 갱신해야 한다(2026-09-03 원고 퀄리티 점검에서 파생됨). 그 저장소에서 `npm run sync:writer-style`을
> 실행하면 이 스킬과의 차이를 보여준다 — 자동 반영은 아니고, 반영 여부는 Claude가 확인 후 판단한다.

사용자는 쌍둥이(지아, 지우)를 키우는 아빠이자 육아 블로거입니다. 이 스킬은 사용자가 실제로 발행했던 원고들의 문체와 구조를 그대로 재현해, 새로운 주제가 주어졌을 때도 "이 사람이 직접 쓴 글" 같은 원고를 만들어내는 것을 목표로 합니다. 아래 패턴은 규칙이라기보다 이 사용자 특유의 글쓰기 습관이니, 형식을 억지로 끼워맞추기보다 왜 이렇게 쓰는지(공감 → 근거 → 실전 경험 → 다독임)를 이해하고 자연스럽게 녹여내세요.

## 글의 전체 흐름

사용자의 글은 거의 예외 없이 이런 흐름을 탑니다. 매 항목이 다 필요한 건 아니지만 순서 자체는 지키는 게 좋습니다.

1. **개인적인 에피소드로 오프닝** — "지난달 영유아 검진을 다녀왔습니다", "며칠 전 저희 쌍둥이들이 고열이 오르기 시작하더니" 처럼, 육아 정보 나열이 아니라 실제 겪은 상황 묘사로 시작합니다.
2. **공감대 형성** — "사실 이런 고민, 저만 하는 게 아니더라고요" 같은 문장으로 독자도 같은 고민을 하고 있을 거라는 걸 짚어줍니다.
3. **글을 쓰게 된 계기 밝히기** — "그래서 이번 기회에 ~ 찾아봤습니다/정리해볼게요"로 자연스럽게 전환합니다.
4. **결론이나 핵심 메시지를 먼저 던지기** — 본격적인 정보 전달 전에 안심시키는 톤의 핵심 요지를 먼저 제시하는 경우가 많습니다. "결론부터 말씀드리면"은 이때 쓸 수 있는 여러 표현 중 하나일 뿐, 매 글 오프닝마다 기계적으로 붙이는 고정 문구가 아닙니다 — 문단 내용 자체가 이미 답이라는 걸 보여주면 충분합니다.
5. **공식 자료·전문가 근거 제시** — 질병관리청, 대한소아과학회 같은 신뢰할 수 있는 기관명을 명시하고, "~라고 하더라고요", "~라고 해요"로 자연스럽게 인용합니다. 숫자(개월 수, cm, kg, 잠복기 일수 등)는 구체적으로 씁니다.
6. **쌍둥이 실제 경험 녹이기** — 지아·지우 이야기를 예시로 넣어서 근거를 사용자 삶에 착 붙입니다. 둘이 다르게 반응했던 디테일(한 명은 더 크다, 한 명은 더 잘 먹는다 등)을 구체적으로 씁니다.
7. **"저희가 실제로 하는/체크하는 것들" 번호 리스트** — 글의 핵심 실용 정보 파트. 번호(1, 2, 3...)를 매기고, 각 항목은 소제목 한 줄 + 설명 + 실제 시행착오 경험을 함께 씁니다. 처음엔 실패하거나 힘들었던 이야기를 솔직하게 넣는 게 이 사용자 특유의 톤입니다("처음에는 불을 끄면 책 더 읽어달라며 울었어요").
8. **주의 신호·병원 가야 할 때 등 실용 안전 정보** (해당되는 주제일 경우) — 리스트나 짧은 문장으로 명확하게.
9. **마무리** — 따옴표로 감싼 한 문장짜리 다짐/메시지를 강조하고("아이들은 몸도 마음도 저마다 각자의 속도로 자란다"), 같은 고민을 하는 독자에게 위로나 응원을 건네며 끝맺습니다.
10. **해시태그** (선택) — 주제 키워드를 #으로 나열. 모든 글에 있는 건 아니니 사용자에게 필요 여부를 물어봐도 됩니다.

## 문체와 어조

- 존댓말이지만 딱딱하지 않은 구어체: "~하더라고요", "~더라고요", "~인 것 같아요", "~였어요", "~해요"를 자연스럽게 섞어 씁니다. "~습니다"는 문단을 여닫을 때(오프닝, 클로징)나 힘줘 말할 때 정도만 씁니다.
- 문장은 짧고 담백합니다. 화려한 수식어나 이모지는 거의 쓰지 않습니다.
- 완벽한 육아 전문가처럼 말하지 않고, 같이 고민하고 시행착오를 겪는 동료 부모의 톤을 유지합니다. "저도 '이게 맞나' 싶어서 포기하고 싶었던 순간이 있었어요" 같은 솔직한 고백이 자주 등장합니다.
- 자료를 인용할 때는 "~자료를 찾아보니", "~라고 해요/하더라고요"로 자연스럽게 녹이고, 출처 기관명은 정확히 명시합니다(질병관리청, 대한소아과학회 등 주제에 맞는 실제 기관).
- 쌍둥이 이름(지아, 지우)이나 "저희 쌍둥이", "저희 남매", "저희 부부" 같은 표현으로 가족 등장인물을 구체적으로 언급합니다. 이름을 넣을 상황이면 지아/지우를 쓰되, 어색하면 "저희 아이들", "저희 쌍둥이"로 대체합니다.

## 형식(포맷팅) 특징

이 사용자는 마크다운 헤더(#, ##)를 쓰지 않습니다. 대신:

- 소제목은 그냥 굵기 없는 한 줄 문장으로 씁니다 (예: "26개월 전후, 실제 평균 키·몸무게는 이 정도예요").
- 문단 사이는 빈 줄로 구분하고, 짧은 문단(1~3문장)을 자주 씁니다.
- 리스트는 "1. 2. 3." 같은 번호나 "-" 대신 굵은 소제목 한 줄 + 이어지는 설명 문단으로 구성하는 경우가 많습니다(원고를 그대로 마크다운으로 옮길 때는 자연스럽게 볼드 소제목 정도로 처리해도 됩니다).
- 최종 결과물은 블로그(네이버 블로그류)에 바로 붙여넣을 수 있는 평문 형태로 작성하세요. 마크다운 아티팩트가 필요하면 헤더 남발 없이 위 스타일을 최대한 살려주세요.

## 원고 작성 절차

1. **주제와 소재 파악하기**: 사용자가 어떤 주제로 쓰고 싶은지, 관련된 실제 에피소드(지아/지우 이야기, 최근 겪은 일)가 있는지 확인합니다. 없다면 자연스럽게 물어보세요 — 이 사용자의 글은 항상 실제 경험에서 출발하기 때문에, 에피소드 없이 정보 나열부터 시작하면 톤이 완전히 어긋납니다.
2. **근거 자료 조사**: 주제에 맞는 공신력 있는 기관 자료(질병관리청, 대한소아과학회, 육아정책연구소 등)를 web_search로 찾아 구체적 수치나 팩트를 확보합니다. 인용 시 저작권 규정을 지켜 원문을 그대로 베끼지 않고 사용자의 문체로 풀어씁니다.
3. **위 흐름(1~10번)에 맞춰 초안 작성**: 모든 섹션을 기계적으로 다 채우기보다, 주제에 맞게 자연스럽게 가감합니다. 예를 들어 감염병 주제면 "병원 가야 하는 신호"가 중요하고, 수면 루틴 주제면 "체크리스트"가 중요합니다.
4. **어조 재검토**: 초안을 다 쓴 뒤, 위 "문체와 어조" 항목과 대조해서 너무 정보성/설명체로 흐르지 않았는지, 실제 경험담과 솔직한 톤이 충분히 섞여 있는지 확인하고 다듬습니다.
5. **결과물 전달**: 분량이 짧지 않은 완결된 글이므로 마크다운 파일(.md) 아티팩트로 만들어 제공합니다. 필요하면 해시태그 추가 여부를 사용자에게 물어봅니다.

## 참고: 스타일 예시 원고

아래는 사용자가 실제로 발행했던 원고 3편의 핵심 특징 요약입니다. 막히면 이 패턴으로 돌아가세요.

- **영유아 성장/키 고민 글**: 검진 다녀온 경험 → 다른 부모들도 비슷한 고민 → 질병관리청 성장도표 수치 인용 → 쌍둥이 키 차이 경험담 → "숫자보다 흐름이 중요" 전문가 관점 → 체크리스트 4가지 → "아이들은 저마다의 속도로 자란다"는 메시지로 마무리, 해시태그.
- **수족구병 투병기**: 여름 불청객이라는 캐치프레이즈로 시작 → 질병 정보(원인균, 잠복기, 증상) → 실제로 했던 대처 5가지(차가운 음식, 수분 섭취, 물집 관리, 해열제, 격리) → 병원 가야 하는 위급 신호 → 예방 수칙 → 응원 메시지로 마무리.
- **쌍둥이 재우기 루틴 글**: 쌍둥이 재우기의 고충 토로 → 아내와 함께 루틴을 정한 계기 → 대한소아과학회 자료로 수면 리듬 근거 제시 → 실제 밤 루틴 4단계(순서, 시간표, 환경, 잠드는 방식) → 적응까지 걸린 기간과 힘들었던 순간 솔직 고백 → 체크포인트(낮잠, 배고픔, 컨디션) → "완벽한 루틴은 없다, 꾸준함이 중요하다"는 메시지로 마무리.

공통적으로: 정보 전달이 목적이 아니라 "같은 고민을 하는 부모에게 공감과 실전 팁을 나눠준다"는 태도가 이 사용자 글쓰기의 핵심입니다. 원고를 쓸 때 이 태도를 가장 먼저 챙기세요.
