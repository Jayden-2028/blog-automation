# 공통 문체(voice) — 모든 카테고리의 어투·어미·인칭 규칙

> 2026-09-16 신설. 원고마다 어투가 달라 블로그 전체의 톤이 흔들린다는 사용자 지적으로, 카테고리
> 파일(parenting/entertainment/trend)에 흩어져 있던 "문체와 어조" 절을 이 파일 하나로 모았다.
> 카테고리 파일은 이제 **글의 흐름·구조·제목 기법**만 담당하고, 어투·어미·인칭은 전부 여기를 따른다.
> 기준은 trend 카테고리가 쓰던 "존댓말 기반에 담백한 격식이 섞인 개인 블로거 톤"이다(사용자 결정).
>
> **`incident`(사건·사고)는 이 파일을 적용하지 않는다** — `incident.md`의 습니다체 통일·1인칭 금지가
> 그대로 유일한 기준이다(사용자 결정, 2026-09-16).
>
> 사실·헤지·인용 태도는 `rules/facts-and-hedging.md`가 이 파일보다 항상 우선한다.

## 1. 한 줄 요약

존댓말. **정보는 `~합니다/~입니다`로 또렷하게, 화자의 반응과 독자에게 건네는 말은 `~해요/~예요/~죠`로
부드럽게.** 두 어미가 한 글 안에서 자연스럽게 섞이되, 문단 하나가 통째로 `~해요`로만 끝나 가볍거나
통째로 `~습니다`로만 끝나 딱딱해지지 않게 한다.

## 2. 어미 — 문장의 역할로 고른다

| 문장 역할 | 어미 | 예 |
|---|---|---|
| 사실·정보·수치 전달 | `합니다 / 입니다` | "지원금은 2026년 8월 기준 30만 원입니다." |
| 화자의 반응·의견·소감 | `해요 / 예요 / 죠 / 거예요` | "저는 이 부분이 제일 반가웠어요." |
| 독자에게 말 걸기·제안 | `해요 / 세요 / 보세요` | "신청 전에 지역부터 확인해 보세요." |
| 오프닝 첫 문장 · 마무리 마지막 문장 | `합니다 / 입니다` | 글의 시작과 끝은 격식으로 여닫는다 |

**쓰지 않는 어미**(글마다 톤이 흔들리던 주범 - 검수 코드 `checkVoice`가 1건이라도 경고한다):

- `~더라고요`, `~네요`, `~거든요`, `~고요`, `~잖아요`, `~답니다`, `~하죠?`(동의 강요), 문장 끝의 `~는데요`
- 반말·평어체(`~다`, `~했다`)를 본문 서술에 쓰지 않는다. 예외: 소제목·목록 항목의 명사형 종결,
  따옴표로 감싼 인용문·다짐 문장("아이들은 저마다의 속도로 자란다").

```
(X) 저희 쌍둥이도 그랬거든요. 처음엔 잘 안 되더라고요.
(O) 저희 쌍둥이도 그랬어요. 처음엔 잘 되지 않았습니다.

(X) 지원금은 30만 원이라고 하네요.
(O) 지원금은 2026년 8월 기준 30만 원입니다.
```

## 3. 인칭과 호칭

- 화자는 "저". 가족을 말할 때만 "저희"(저희 쌍둥이, 저희 집). "필자", "본인", "나"는 쓰지 않는다.
- 독자는 부르지 않는 것이 기본이다. 꼭 필요하면 "여러분"을 글 전체에서 한 번 정도 — 매 문단 붙이지 않는다.
- 화자의 정체(쌍둥이 아빠)는 parenting에서만 전면에 나온다. 다른 카테고리에서는 소재와 자연스럽게
  이어질 때 한 문장 정도만 묻어난다("육퇴 후 보기 좋은 작품입니다").

## 4. 문장과 표현

- 문장은 짧게. 한 문장에 정보 하나. 60자를 넘기면 둘로 나눈다.
- 감탄사·이모지·말줄임표·물결(~)·느낌표 연발로 감정을 연출하지 않는다. 느낌표는 글 전체에서 2개 이하.
- "충격", "역대급", "소름", "미쳤다", "찐", "레전드" 같은 과장·유행어를 **본문**에 쓰지 않는다.
  제목의 후킹 기법은 카테고리 파일 규칙을 따른다 — 제목과 본문의 기준이 다르다.
- 정형 문구를 매 글 반복하지 않는다: "저도 궁금해서 찾아봤어요", "결론부터 말씀드리면", "오늘은
  ~에 대해 알아보겠습니다", "지금부터 하나씩 살펴볼게요". 자연스러운 자리에서 한 편에 한 번이 상한이다.
- 논쟁적 소재는 감정적 비난·단정 대신 사실과 의견을 문장 단위로 분리한다. 의견 문장은
  "저는 ~라고 봅니다/생각해요"로 화자 소유를 분명히 한다.
- 인용은 실제 인물·기관을 주어로 직접 쓴다("질병관리청은 ~라고 안내합니다"). "~라고 해요/하더라고요"로
  확인된 사실을 전달자 화법으로 흐리지 않는다(`rules/facts-and-hedging.md`).

## 5. 오프닝과 마무리

- 오프닝: 소재를 첫 두 문장 안에 바로 던진다. 오프닝의 **구조**(에피소드/개인 반응/소식 직행)는
  카테고리 파일이 정하고, 어미는 위 §2 표를 따른다.
- 마무리: 요약 한두 문장(합니다체) + 독자에게 건네는 한 문장(해요체). 댓글 유도 질문은
  trend·entertainment에서 선택, parenting은 응원 메시지. 소제목 없이 이어 쓴다.

## 6. 자기 점검(저장 전)

- [ ] 본문 서술문에 `~더라고요/~네요/~거든요/~고요/~잖아요/~답니다`가 **0개**다
- [ ] 반말 종결(`~다/~했다`)로 끝나는 본문 서술문이 0개다(따옴표 안 인용·소제목·목록 제외)
- [ ] 정보 문장은 합니다체, 반응·제안 문장은 해요체로 역할이 갈려 있다
- [ ] 오프닝 첫 문장과 마무리 마지막 문장이 `합니다/입니다`로 끝난다
- [ ] 정형 문구가 한 편에 1회 이하다
- [ ] 느낌표 2개 이하, 이모지 0개, 본문에 과장·유행어 0개
