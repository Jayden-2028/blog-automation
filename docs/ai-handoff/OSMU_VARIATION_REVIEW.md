# OSMU 배리에이션 품질 리뷰 (2026-08-31)

`generateArticleVariant`가 만든 채널별 배리에이션 원고 2건을 기준 원고와 비교 검토했다.

## 표본

| job | 기준 원고 | 배리에이션 |
|---|---|---|
| 맥도날드 감튀 홀더 (living) | article #9 (2795자) | article #10 blogspot (3078자) — 실제 발행됨 |
| 보조금24 (living) | article #7 (2209자) | tistory 샘플 (2484자) — 스크립트로만 생성 |

`.local/osmu-review/<jobId>/`에 전문 보관.

## 좋은 점 (그대로 유지)

- **사실 보존 완벽**. 두 표본 모두 수치·날짜·금액·제도명·인용을 한 글자도 안 바꿨고, 없는 사실을
  지어내지 않았다("절대 규칙 - 사실 보존"이 작동).
- **제목·인트로·소제목·FAQ는 실제로 새로 씀**. 소제목이 전부 질문형으로 바뀌고("어떤 물건일까",
  "왜 직접 조회해야 하나요?"), FAQ 5문답이 잘 구성됨.
- **본문 내 출처 호출 제거**됨(기준의 "(출처: blog.naver.com/...)"이 배리에이션엔 없음).
- SEO 구조 충족: 첫 100자 안 키워드, 질문형 H2, FAQ, 요약, 참고 자료 보존.
- 톤 자연스러움(korean-humanize 통과 수준).

## 문제 (수정함)

### 1. 근접 중복 문단 - 특히 "## 요약" (2026-08-31 프롬프트 강화)

두 표본 모두에서 아래 구간이 기준 원고와 **85~99% 동일**(동의어 치환 + 문체만 변경):
- **"## 요약" / "## 정리"** — 가장 심함. 기준 결론 문장을 거의 그대로 재사용.
- 절차 번호 목록(보조금24 5단계) — 99% 동일
- 설명형 불릿(혜택알리미/미환급금/청년일자리도약장려금 3항목) — 출처 표기만 빼고 동일
- 효용 설명 문단(맥도날드 "도움이 될까") — 문장 구조 그대로

**수정**: 프롬프트에 "다시 쓰기가 아니라 다시 기획하기" 규칙 블록 추가.
- "## 요약"은 기준 결론 재사용 금지, 배리에이션이 다룬 소제목을 새로 압축
- 연속 3어절 이상 겹침 금지(숫자·날짜·제도명·URL 예외)
- 설명형 목록은 묶거나 나눠 개수 다르게, 절차 목록은 앞뒤 설명 문장을 새로

### 2. 배리에이션 메타데이터를 버리고 있었음 (2026-08-31 배선)

`generateArticleVariant`가 `searchDescription`/`slug`/`tags`(5~10개)를 생성하는데 발행 코드가
안 썼다:
- Blogspot: category 라벨 1개만. 검색 설명 미사용 → **`searchDescription`을 `customMetaData`로 전달**
- 티스토리: category 라벨 1개만(자유 태그인데) → **배리에이션 `tags`를 그대로 입력**

⚠️ `articles`에 metadata 컬럼이 없어 **재사용 경로**(배리에이션 원고는 있는데 발행이 실패해
다음 폴링에서 재시도)에서는 메타데이터를 잃고 category 라벨로 폴백한다. 첫 발행에서만 완전 활용.
필요해지면 `articles.metadata jsonb` migration.

## 개선 검증 (2026-08-31, 프롬프트 강화 후 재생성)

보조금24 tistory 배리에이션을 강화된 프롬프트로 재생성해 기준 원고와 다시 비교:

| 구간 | 강화 전 | 강화 후 |
|---|---|---|
| "## 요약" | 기준 결론 ~90% 복사 | ✅ **이 글이 다룬 소제목을 새로 압축** ("서비스 성격, 상황별 항목, 다섯 단계, 부가 확인법을 다뤘습니다") |
| 설명형 불릿(부가정보 3항목) | 출처만 빼고 그대로 | ✅ **"두 갈래"로 재구조화**, 산문으로 녹임 |
| 청년/육아 항목 목록 | 불릿 그대로 | ✅ 산문 문장으로 ("사회초년생이거나 취업 준비 중이라면...") |
| 5단계 절차 | 그대로 + 새 프레이밍 없음 | 그대로(불가피) + ✅ **앞뒤 원본 분석 문장으로 감쌈** ("놓치기 쉬운 부분은 4·5번") |
| 사실 보존 | 완벽 | ✅ 완벽 유지(약 1분, 2026-08-28, 비수도권 우대, 제도명 전부) |

길이도 2484자 → 2955자(원본 분석이 늘어서). **프롬프트 강화 효과 확인됨.**

## 미해결 / 관찰

- 절차 목록·고유명사 목록은 정확성상 그대로 둘 수밖에 없다 - 이제 소수 비중 + 원본 서술로 감싸
  중복 위험은 낮음.
- n=2(둘 다 living). entertainment/ott/parenting 카테고리는 첫 자동 발행 후 재검토.
- 배리에이션 메타데이터 재사용 경로 손실은 `articles.metadata jsonb` migration으로 해결 가능(보류).
- 샘플 스크립트: `npm run review:dump-articles <jobId>` / `npm run review:gen-variant <jobId> <channel>`.
