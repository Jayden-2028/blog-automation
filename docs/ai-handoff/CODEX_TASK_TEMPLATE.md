하나의 구체적인 결과만 넣는다.

- Task ID:
- 작업 유형: `read` 또는 `write`

완료 시 무엇이 달라져야 하는지 1~3문장으로 작성한다.

여기에 기록한다.

## 완료 조건

- [ ] 기능 또는 조사 결과 조건 1
- [ ] 조건 2
- [ ] 관련 테스트 통과
- [ ] `npm run build` 통과(코드 변경 시)
- [ ] 범위 밖 변경 없음

## 결과 보고 형식

1. 완료한 내용
2. 변경한 파일
3. 검증 결과
4. 남은 위험/미확인 사항
5. Claude가 검토하거나 결정할 항목

작업 종료 후 commit/push하지 않는다. Claude가 diff와 검증 결과를 독립적으로 검토한다.
